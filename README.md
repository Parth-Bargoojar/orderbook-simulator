# Order Book Matching Engine — Educational Simulator

A high-performance, interactive, single-page educational simulator for an Order Book Matching Engine. This application visualizes how limit and market orders interact under price-time priority (FIFO) and displays real-time price impact, spreads, and candlestick charts.

## Features
- **Visual Order Book:** Dynamic 8 × 8 depth display showing bid and ask queues.
- **Order Interaction:** 
  - **Limit Orders:** Add liquidity at custom price levels.
  - **Market Orders:** Consume liquidity instantly, highlighting slippage and execution depth.
- **Session Candlestick Chart:** A live visualizer displaying Open, High, Low, and Close (OHLC) values based on trade executions.
- **Trade Log:** Real-time log showing executed trades, volumes, and counterparty matches.
- **Premium UI:** Apple-style aurora backdrop, frosted glass cards (Tailwind CSS), and smooth GSAP animations.

## How to Run
Simply open `order-book-simulator.html` in any modern web browser. No installation or build steps are required.
